# Azikel's Tasty Food

## Website Design & Development Brief

Build a premium, modern, responsive 5-page website for **Azikel's Tasty Food**, a Gauteng-based catering and events company.

The company provides catering and event-related services for private celebrations, weddings and corporate functions.

The website must feel **warm, premium, celebratory and trustworthy**. Avoid the generic AI-generated website look: no excessive floating cards, random gradients, oversized empty sections, repetitive icon grids, or generic SaaS-style layouts.

The finished website should feel like a professionally designed South African catering and events brand.

---

Create the following five pages:

1. **Home**
2. **About Us**
3. **Services**
4. **Gallery / Our Work**
5. **Contact**

All pages must share the same navigation, footer, typography, colour system and overall visual identity.

# 3. Brand Direction

The visual identity should communicate:

**Good food + beautiful occasions + professional service + African warmth**

The company should not look like a fast-food restaurant.

It should look like a business capable of handling:

* Intimate celebrations
* Large family functions
* Weddings
* Birthday parties
* Corporate events
* Professional catering contracts

## Suggested Colour Palette

Use a sophisticated palette inspired by the logo:

* Deep black / charcoal
* Warm cream / off-white
* Champagne gold
* Muted warm beige
* Small amounts of rich accent colour where appropriate

Gold should be used as an **accent**, not across every element.

Avoid excessive gradients.

## Typography

Use an elegant combination of:

* Sophisticated display/serif font for major headings
* Clean modern sans-serif for body copy
* Optional script-style typography used very sparingly for decorative moments

Typography should feel editorial and premium.

# 20. Important Design Instruction

**DO NOT produce a generic AI-generated website.**

Avoid the common pattern of:

Hero → three cards → icon grid → testimonial cards → CTA → footer.

Instead, design the website like a boutique hospitality/event brand.

Use:

* Large photography
* Editorial layouts
* Overlapping compositions where appropriate
* Asymmetric sections
* Generous whitespace
* Strong typography
* Alternating image/text compositions
* Full-width visual moments
* Carefully controlled gold accents

Every page should feel related, but not every section should use exactly the same layout.

The site should feel **custom-designed for Azikel's Tasty Food**.

---

# 21. Important Content Rule

Do not invent:

* Testimonials
* Customer names
* Awards
* Certifications
* Years in business
* Number of events completed
* Menu prices
* Package prices
* Staff names
* Social media accounts

Where information has not yet been supplied, build the UI so it can easily be added later.
